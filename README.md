# ☕ Python Coffee Machine Simulator

A beginner-friendly Python project that simulates a digital coffee machine. Users can order drinks, manage machine resources, process coin payments, and calculate accurate change.

## 🚀 Features
* *Interactive Menu:* Order Espresso, Latte, or Cappuccino.
* *Resource Management:* Tracks water, milk, and coffee beans.
* *Coin Processor:* Accepts quarters, dimes, nickels, and pennies.
* *Smart Validation:* Checks if resources are sufficient and handles transactions seamlessly.

## 🛠️ How to Run
1. Download or clone this repository.
2. Open your terminal or command prompt in the project folder.
3. Run the following command:
   bash
   python main.py
